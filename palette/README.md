# Палитра: мягкое лето

Локальный мини-проект карточки в формате имидж-студии (фото слева, сетка 5×5 справа).

Цветотип по вашему кадру в машине: **мягкое лето**.  
Параметры: 42 года, 165 см, 110 кг, рубашка **54**, крой regular / classic.

Лицо **не генерируется**. В карточку попадает только файл, который вы положите в эту папку.

## Как собрать карточку на своём ПК

1. Скачайте эту папку `palette` (клонируйте репозиторий или скопируйте каталог).
2. Положите своё фото сюда под именем `photo.jpg`  
   (подойдут также `photo.jfif`, `photo.jpeg`, `photo.png`).
3. Дважды нажмите `собрать-карточку.bat`.

Скрипт сам:
- поставит Python-пакет Pillow;
- если `photo.jpg` ещё нет — возьмёт самый новый `.jfif` / `.jpg` из `D:\загрузки(d)` или из `Downloads`;
- сохранит `карточка.png` и откроет её.

Можно указать файл явно:

```bat
собрать-карточку.bat "D:\загрузки(d)\f13bceed-58bf-4e21-b728-560900c3f2a9.jfif"
```

Нужен [Python](https://www.python.org/downloads/) с галочкой **Add python.exe to PATH**.

### Без bat (Linux / macOS)

```bash
cd palette
python3 -m pip install -r requirements.txt
cp /путь/к/снимку photo.jpg
python3 make_card.py
```

## Что на сетке

| Подпись | Зачем |
|---|---|
| **база** | нейтрали: брюки, куртка, обувь (navy и графит вместо чёрного) |
| **основа** | рубашки, джемперы, поло |
| **акцент** | около 10% образа |

Navy у лица на вашем кадре уже свой. Чёрная кожанка тяжелее, чем водолазка.
