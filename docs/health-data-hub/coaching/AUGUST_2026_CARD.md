## Правила коучинга (из опыта августа)

### Избегать

Teremok blini, mayo, doctor sausage, pirozhki, Tanuki rolls, McDonald's, liver stroganoff, fried liver, тяжёлый Caesar + lapsha в один приём.

### Предпочитать

Mealty salmon/chicken, VkusVill su-vide chicken, tvorog + protein chips, eggs without mayo.

### Завтрак

Один источник углеводов — не kasha + syrniki + banana одновременно.

### Hub API

- Read: `GET /api/health/day/{YYYY-MM-DD}` (базовый URL hub — см. [README](../README.md))
- Hub UI: `/hub/`
- **Не доверять** sleep 14–15h в hub — ориентир Mi Fitness ~6–7h.
- Nutrition часто отстаёт на ужин — сверять с FatSecret.
