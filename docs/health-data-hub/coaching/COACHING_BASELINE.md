## Быстрая сверка (чеклист)

1. Прочитать `docs/health-data-hub/coaching/COACHING_BASELINE.md` и **актуальную** карточку: [SEPTEMBER_2026_CARD.md](./SEPTEMBER_2026_CARD.md) (август — эталон).
2. Загрузить день из hub: `GET /api/health/day/{date}` (базовый URL — [README](../README.md)).
3. Сравнить с **рабочими целями** ниже (не с дефолтами FatSecret ~2400 ккал).
4. Проверить: белок ≥120 г, ккал 1900–2100, жир ≤70 г, шаги ≥6000, ужин залогирован.
5. Если паттерн повторяется — **явно назвать** (жир выше цели, Snickers/сырники/Teremok, дыра в логе, `grams` FatSecret ≠ граммы).

## Лекарства и АД (для коучинга)

- **Эдарби АМ** с **11.09**: 1 табл. азилсартана **40 мг** + 1 табл. амлодипина **5 мг** раз в сутки (как назначил кардиолог). Эдарби 80 в тот же день не принимать.
- Не путать с **Эдарби Кло** (азилсартан + хлорталидон) и со старым **Эдарби 80** моно.
- Коуч **не меняет** дозы. Следить: утреннее АД, отёки голеней (амлодипин), головокружение при вставании. Эффект амлодипина по АД обычно не «с первой таблетки» — смотреть тренд 7–14 дней, не паниковать на 12–13.09.
- Соль / колбаса / Teremok / «по-французски» / Snickers по-прежнему бьют по диастолике — на старте АМ еду не расслаблять.

## Hub: качество данных (чтобы не врать в карточке)

- **`nutrition.items[].grams`** у FatSecret = `number_of_units`. Если значение **< 20** — это порции, не граммы. Пример: шницель `4.0` → одна упаковка ~400 г, не 4 блюда. Смотри `qty_label` / `qty_is_servings` в API.
- Банан/персик с 3–4 одинаковыми строками — **спросить** пользователя (09.09 персик был один).
- Сон `< 3 ч` или `sleep.incomplete` — неполная сессия, не ночь.
- Пустой nutrition 05–06.09 — дыра лога, не ноль ккал.
