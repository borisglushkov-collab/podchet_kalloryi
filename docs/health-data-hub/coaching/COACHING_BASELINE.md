# Coaching baseline — сверка и корректировка

> **Для Cloud Agent / коуча:** перед рекомендациями по питанию, весу и АД **прочитай этот файл** и **последнюю месячную карточку** в этой папке.

---

## Быстрая сверка (чеклист)

1. Прочитать `docs/health-data-hub/coaching/AUGUST_2026_CARD.md` (или актуальный `*_CARD.md`).
2. Загрузить день из hub: `GET /api/health/day/{date}` (базовый URL — [README](../README.md)).
3. Сравнить с **целями сентября** (из карточки августа, раздел «Цели на сентябрь»).
4. Проверить: белок ≥120 г, ккал 1900–2100, шаги ≥6000, ужин залогирован.
5. Если паттерн августа повторяется — **явно назвать** (неполный лог, Subway, пирожки и т.д.).

## Лекарства и АД (для коучинга)

- **Эдарби АМ** = 1 табл. азилсартана **40 мг** + 1 табл. амлодипина **5 мг** раз в сутки (как назначил кардиолог).
- Не путать с **Эдарби Кло** (азилсартан + хлорталидон) и со старым **Эдарби 80** моно.
- Коуч **не меняет** дозы. Следить: утреннее АД, отёки голеней (амлодипин), головокружение при вставании.
- Соль / колбаса / Teremok / «по-французски» по-прежнему ухудшают диастолику — усиливать контроль еды на старте новой схемы.
