## Hub: не путать порции FatSecret с граммами

Поле `grams` в API часто = `number_of_units`, не граммы:

| В логе | Как читать |
|---|---|
| Mealty шницель `grams: 4.0` | скорее 4×100 г = **400 г, одна упаковка**, не 4 блюда |
| сыр `grams: 0.3` | ~30 г (0.3 порции), не 0.3 г |
| огурец `grams: 150` | 150 г — уже граммы |
| банан / персик ×3–4 записи | сначала спросить пользователя (09.09 персик был один) |

Сон <3 ч в hub = неполная сессия (как 09.09 2ч12), не ночной сон. Обновить позже.
